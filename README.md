# 내 가계부 (웹 배포판)

개인 가계부 화면입니다. 이 저장소에는 **프로그램 코드만** 있고, 거래 데이터·사람 이름·설정 파일은 없습니다.

- 주소: https://faalcoholswab.github.io/gagyebu/
- 가계부 엑셀은 각자의 기기 브라우저 안에서만 읽고 고칩니다. 화면에 넣은 보안 설정(Content-Security-Policy)이
  외부 연결·외부 이미지·폼 전송을 모두 막아, 거래 내용이 이 사이트나 다른 곳으로 전송되지 않습니다.
- 아이폰: Safari로 주소를 열고 공유 버튼 → **홈 화면에 추가**. 처음 연 뒤에는 인터넷 없이도 열립니다.
- PC: Chrome·Edge로 열면 가계부 폴더의 가계부.xlsx에 바로 저장합니다.

포함한 라이브러리: Apache ECharts, SheetJS Community Edition(라이선스는 licenses/ 폴더).
